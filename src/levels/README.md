# Level maps

Each level is a plain JS file exporting `{ id, name, world, questions, map }`.
`map` is a block of text inside ``String.raw`…` `` (so `\` stays a back-slash): **one character = one 64 px tile**, rows top → bottom.
Levels 2-1 … 5-2 are generated by `python3 tools/make-levels.py`; you can also edit any map by hand.
Short rows are padded with empty tiles. Make maps 16 rows tall, with the ground surface on row 13
(the top 4 rows sit above the normal view: a good place for the hidden Star Carrot).

| Char | Meaning |
|---|---|
| `.` | empty |
| `#` | ground (edges and corners are drawn automatically) |
| `=` | floating platform — jump up through it, land on top |
| `~` | water (falling in → balloon rescue) |
| `P` | Hoppy's start |
| `c` | small carrot |
| `*` | hidden Star Carrot (one per level, needed for 3 stars) |
| `m` | bouncy mushroom (hold jump while landing for a super bounce) |
| `F` | checkpoint flower (the level resumes here if the child leaves) |
| `G` | Stone Gate — put it on the tile just above the ground |
| `?` | Question Box — 2–3 tiles above where Hoppy stands |
| `_` | Broken Bridge plank spot — a run of `_` in the ground row over a gap, with `~` water below |
| `L` | Sleepy Log — bottom tile of a 2-tile-high tunnel (ground above it) |
| `K` | Carrot Lift — on the ground, right next to a cliff too tall to jump (6+ tiles) |
| `B` | boss gate — on the tile just above the ground |
| `C` | Golden Carrot — the end of the level, on a little hill |
| `I` | slippery ice (solid ground, but Hoppy slides) |
| `/` `\` | snowy ground slope going up / down to the right (put ground under each slope tile) |
| `)` `(` | rainbow slide going down / up to the right (one-way: land on it from above and whoosh) |
| `w` | swimming water — Hoppy swims (tap to swim up); things placed in it stay underwater |
| `T` | turtle: rides along the `-` path next to it, at the water line (row above `~` water) |
| `D` | drifting cloud: rides along the `-` path next to it (put it in the ground row across a gap) |
| `-` | path for a turtle or cloud (the ride waits at each end) |
| `S` | snowballs roll from here down the slope on its left |

Rules of thumb (GAME_DESIGN §4–5): generous gaps (≤ 3 tiles for pits, wider only with a turtle,
cloud or rainbow to cross them), no spikes, keep high platforms more than 9 tiles away from tunnel hills
and lift cliffs (so they can't be skipped), 4–6 screens long
(80–120 columns), 6–10 challenges, the layout pattern
START → Gate → platforms + carrots → Question Box → Bridge → mushroom → Gate → Star Carrot → Log → Gate → hill → Golden Carrot.
Run `node --test` after editing: the level tests check every map is well formed.

## Endless Meadow
After 5-2 the map opens **Endless Meadow**. Its rounds are not hand-made: `src/engine/endless.js`
builds each one from the same kinds of chunks (gates, Question Boxes, bridges, tunnels, pits, hills,
mushrooms) using a seed that is saved in the child's profile, so leaving and coming back gives the same map.
`tests/endless.test.js` runs the same fairness checks on 60 generated rounds as on the hand-made levels.
