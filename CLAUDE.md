# CLAUDE.md — project rules for Carrot Quest Baby

You are building **Carrot Quest Baby**, a Mario-style platformer for 3-year-olds that teaches uppercase and
lowercase letters and the numbers 1–20 on iPad. It is a copy of Carrot Quest (the 7-year-old times-tables game in
`../mult-game`), with its own repo, save key (`carrotquestbaby.v1`) and service-worker cache (`carrot-quest-baby-*`).
The full design is in `GAME_DESIGN.md`; its **Baby edition** section at the top overrides the rest.
Read it before every task and follow it exactly; ask if something is unclear.

## Tech rules
- Use **Phaser 3** (arcade physics). Install it once with npm and copy `phaser.min.js` into `lib/`;
  load it from there with a plain `<script>` tag. No CDN and no runtime network requests.
- Game code: plain JavaScript ES modules in `src/`. No bundler or build step; it must run with `npx serve .`.
- Art: draw every sprite as SVG in code (`src/art/`), then turn it into Phaser textures at boot
  (e.g. `this.textures.addBase64` or by loading SVG data URLs). Animations are sprite frames or tweens.
  Make the art polished and cute — no placeholder rectangles in finished work.
- Sound: synthesised with the Web Audio API in `src/audio.js`. Unlock audio on the first tap (an iOS requirement).
- Speech: `speechSynthesis`, with a toggle.
- Save data: `localStorage`, every read/write wrapped in try/catch with an in-memory fallback.
- PWA: `manifest.webmanifest` (landscape, standalone), `service-worker.js` (cache-first, versioned cache name),
  and icons 180, 192 and 512 px generated by a Node script in `tools/`.
- iOS meta tags: `apple-mobile-web-app-capable`, `apple-touch-icon`, and `viewport-fit=cover`. Respect safe-area insets.

## Game-feel and child-UX rules
- Canvas uses Phaser's scale mode `FIT` with a 1280×720 design size, centred, landscape.
  Show a friendly "please turn the iPad sideways" picture in portrait.
- Touch targets ≥ 100 px for game controls and ≥ 80 px for menu buttons. Multi-touch must work (run + jump together).
- Forgiving physics: coyote time ≈ 100 ms, jump buffer ≈ 120 ms, variable jump height, double jump.
- No death, no lives, no game over, no red X, no buzzer. Pits → balloon float back; critters → soft knock-back.
- While a maths sign is open, physics is paused and game input is ignored.
- Disable double-tap zoom, text selection and the long-press callout
  (`touch-action: none; user-select: none; -webkit-touch-callout: none;`).
- Respect `prefers-reduced-motion` (no screen shake, fewer particles). Nothing flashes more than 3 times per second.

## Code organisation
```
index.html, manifest.webmanifest, service-worker.js
lib/phaser.min.js
src/main.js                  Phaser config + scene list
src/scenes/                  Boot, Title, Profiles, WorldMap, Level, MathSign (overlay), LevelComplete, Burrow, Parent
src/engine/                  questions.js, mastery.js, levels-config.js  (pure JS, no Phaser, no DOM)
src/levels/                  one text tile map per level (e.g. 1-1.js)
src/art/                     hoppy.js, tiles.js, blocks.js, worlds.js, ui.js — return SVG strings
src/audio.js, src/speech.js, src/save.js, src/controls.js
tests/                       *.test.js run with `node --test`
tools/                       make-icons.js
```

## Working style
- Work in small steps. After each step, say what changed and exactly how to try it on the iPad.
- Keep `src/engine/` pure so it can be unit-tested; run `node --test` before finishing any task.
- Check for console errors, and bump the service-worker cache version whenever files change.
